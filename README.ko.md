# BeatTake

[English README](README.md)

BeatTake는 음악 만들기를 처음 해보는 사람이 그 자리에서 들은 소리로 짧은 곡을 만들 수 있도록 돕습니다. 책상을 두드리거나 지퍼를 여는 소리를 녹음하고 다듬은 뒤 여러 트랙에 배치할 수 있습니다.

**Emong**이 Vibe Forge 출품을 위해 만들었습니다.

## 시작하기

- 웹에서 열고 녹음을 시작할 때 마이크 사용을 허용합니다. 녹음과 곡은 사용한 브라우저에 저장됩니다. [웹 데모 열기](https://maoemong.github.io/BeatTake/)
- Android 7.0 이상에서는 APK를 내려받아 설치할 수 있습니다. 녹음, 편집, 곡 만들기와 재생은 로그인이나 API 키 없이 쓸 수 있으며, 안드로이드에서는 인터넷이 없어도 동작합니다. [APK 다운로드](https://github.com/MaoEmong/BeatTake/releases/download/v1.0.0/BeatTake-1.0.0-android.apk) · [Releases](https://github.com/MaoEmong/BeatTake/releases/tag/v1.0.0)
- 앱은 영어로 시작합니다. **Settings → Language**에서 **한국어**를 선택할 수 있습니다. 일본어와 중국어 간체도 지원합니다.

## 소리로 곡 만들기

1. 홈에서 **소리 녹음하기 → 녹음 시작**을 누르고, 녹음을 끝내면 **정지하고 저장**을 선택합니다.
2. 편집 화면에서 원하는 구간과 음 높이를 정합니다. **미리 듣기**로 확인하고 **다듬은 소리 저장**을 누릅니다. 다른 소리도 같은 방식으로 저장합니다.
3. 홈에서 **곡 만들기**를 열고 곡 이름을 입력합니다. **소리 추가**를 눌러 소리마다 트랙과 시작 시간을 정합니다.
4. **재생**으로 배치를 들어 보고 **저장**합니다. **곡 보관함**에서 다시 재생하거나 편집할 수 있습니다.

## AI 편곡

인터넷에 연결한 뒤 **설정**에 GPT-6 Luna를 사용할 수 있는 개인 OpenAI API 키를 입력합니다. **AI 곡 만들기**에서 다듬은 소리를 하나 이상 고르고, 원하는 분위기가 있다면 적은 뒤 **배치안 만들기**를 누릅니다. 편곡 결과는 곡 편집 화면에서 들어 보고 수정하거나 저장할 수 있습니다.

웹에서는 페이지를 새로 열면 키를 다시 입력해야 합니다. 안드로이드에서는 키를 기기의 보안 저장소에 저장합니다. 편곡 요청에는 고른 소리의 이름과 길이, 편곡 요청 문구, 소리를 구분하는 임시 이름이 들어갑니다. 녹음 파일은 기기나 브라우저의 보관함에 남습니다.

## 개발과 배포

Emong이 녹음부터 곡 편집까지의 사용 흐름을 정하고 Track Lens 화면을 골랐습니다. OpenAI Codex로 구현한 뒤, 별도 검토에서 저장을 빠르게 두 번 누르면 곡이 두 번 저장되는 문제를 찾았습니다. 한 번만 저장되도록 고치고 자동 테스트로 확인했습니다.

실제 편곡을 받아 편집·저장·재생하는 과정을 확인한 뒤 OpenAI를 선택했습니다. 앱은 고른 소리의 트랙과 시작 시간을 제안하도록 요청하고, 결과를 확인한 뒤 편집 화면에 엽니다. [실행과 검증 기록](docs/development.md) · [배포와 Vibe Forge 제출 안내](docs/deployment.md)

## 다음 개발 계획

완성한 곡을 공유하거나 다른 음악 앱에서 쓸 수 있도록 WAV 파일로 내보내는 기능을 추가할 계획입니다. 더 다양한 휴대폰과 모바일 브라우저에서 녹음, 녹음 중단, 재생도 확인할 계획입니다.
