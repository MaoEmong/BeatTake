# 기능 계획과 제출 준비

생활 속 소리를 직접 녹음해 모으고, 모아 둔 소리로 음악을 만드는 Flutter 모바일 앱이다. 아래 기능을 모두 출품 버전에 포함한다. 기존 녹음, 기기 저장, 저장 목록과 재생의 확인 기록은 [실행 및 확인](./development.md)에 있다.

## 개발 작업 순서

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 기존 녹음 확인 | 현재 코드를 바탕으로 녹음, 저장, 재생이 되는지 확인한다. 기존에 저장한 녹음은 앱을 다시 열어도 그대로 재생된다. |
| 2 | 녹음 구간 자르기 | 목록에서 녹음을 열고 구간의 시작과 끝을 고른다. 선택 구간을 미리 듣고 별도로 저장할 수 있다. |
| 3 | 음 높이 바꾸기 | 선택한 구간의 음을 높이거나 낮춰 들어보고 저장한다. 저장한 소리를 앱을 다시 열어도 재생할 수 있다. |
| 4 | 여러 트랙에 소리 배치하고 재생하기 | 다듬은 소리를 원하는 트랙과 시간에 놓고 옮길 수 있다. 두 소리의 시간이 겹치면 함께 들린다. |
| 5 | 소리와 곡 관리 | 곡을 만들고 저장한다. 앱을 다시 열면 소리와 배치가 그대로 남아 수정할 수 있고, 필요 없는 항목은 목록에서 삭제할 수 있다. |
| 6 | AI 자동 편곡 | 사용자가 자신의 AI 서비스 키를 등록한다. AI가 만든 배치안을 트랙 편집 화면에서 열어 재생하고 수정할 수 있다. |
| 7 | 안드로이드 앱 최종 확인 | 대회명과 제작자 이름이 보이는 설치 파일을 만들고, 실제 휴대폰에서 `개발 중 확인할 흐름`을 처음부터 끝까지 실행한다. |

### 임시 화면에서 적용한 방식

- **녹음 편집**은 원본을 보관하고 다듬은 소리를 따로 저장한다. 음을 높이면 소리가 짧아지고, 낮추면 길어진다.
- **곡 편집**은 소리, 트랙, 시작 시간을 기록한다. 곡을 다시 열거나 AI 배치안을 불러올 때 같은 방식으로 표시한다. 곡에 쓰인 소리는 배치를 먼저 지운 뒤 삭제할 수 있다.
- **AI 편곡**은 설정에서 Gemini, Claude, OpenAI 중 하나를 선택해 사용한다. 선택한 서비스에만 소리의 이름과 길이, 편곡 요청을 보내며, 앱에 있는 소리만 올바른 위치에 배치하도록 결과를 확인한다.

## 개발 중 확인할 흐름

1. 실제 안드로이드 휴대폰에서 마이크 사용을 허용하고 소리 두 개를 녹음한다. 앱을 다시 열어 녹음이 남아 있고 재생되는지 확인한다.
2. 각 녹음에서 사용할 구간을 고르고, 음 높이를 바꿔 들어본 뒤 저장한다. 다듬은 소리를 여러 트랙의 원하는 위치에 배치해 함께 재생한다.
3. 곡을 저장하고 앱을 다시 열어 배치가 그대로 남는지 확인한다. 곡을 다시 수정하고, 목록에서 필요 없는 항목을 삭제해 본다.
4. AI 서비스 키를 등록해 녹음한 소리의 배치안을 만든다. 트랙 편집 화면에서 제안된 배치를 재생하고 수정한다.
5. 앱 화면 하단에 대회명과 제작자 또는 팀 이름을 표시한다. [대회 공식 규정 4항](https://vibe-forge.in/rules)

개발하면서 참가 기간 전에 준비한 코드나 문서와 기간 중 새로 작업한 내용을 기록한다. 나중에 설명할 수 있도록 AI에 요청한 내용, 결과를 고친 과정, 직접 판단한 부분도 남긴다. [대회 공식 규정 4·5항](https://vibe-forge.in/rules)

## 모바일 앱 제출 방식

- 완성된 안드로이드 앱의 설치 파일(APK)을 저장소에서 받을 수 있게 하고, 저장소 주소로 전달하는 방안을 우선 검토한다. 이 방식이 허용되지 않으면 설치 파일 직접 첨부가 가능한지 확인한다.
- 공식 규정은 심사위원이 로그인 없이 열 수 있는 공개 데모 주소를 요구하며 저장소 주소 입력은 선택이다. 설치 파일 다운로드 주소를 공개 데모로 인정하는지, 설치 파일을 제출 화면에 직접 첨부할 수 있는지는 공개 안내에서 확인되지 않았다. 참가자 화면이나 주최 측을 통해 확인이 필요하다. [대회 공식 규정 8항](https://vibe-forge.in/rules)
- 제출 가능 여부와 적용 마감은 참가자 화면에서 확인한다. 공식 홈페이지의 대회 종료일, 일정 페이지의 참가자별 마감 안내, 기존 공지의 마감일 표기가 서로 다르다. [대회 홈페이지](https://vibe-forge.in/) · [공식 일정](https://vibe-forge.in/timeline) · [공식 공지](https://vibe-forge.in/announcements)
- 제출 소개와 시연 영상은 앱을 완성할 즈음 준비한다. 공식 안내의 영상 기준은 일반적으로 2분 이내이며, 파일로 올릴 때는 최대 250MB다. `Creative Tools and Design`은 기존 문서에 적힌 후보 분야다. [공식 자주 묻는 질문](https://vibe-forge.in/faq)
