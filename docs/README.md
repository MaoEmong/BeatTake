# BeatTake 프로젝트 인수인계

2026년 11월 23일에 정리했다. 프로젝트 위치는 `E:\portfolio\vibeforge`다.

BeatTake는 휴대폰으로 주변 소리를 녹음하고, 그 소리들을 여러 트랙에 놓아 음악을 만드는 Flutter 앱이다. 책상 두드리는 소리나 문 닫는 소리처럼 내가 직접 모은 소리로 짧은 곡을 만들 수 있게 하는 것이 목표다. Vibe Forge에 제출할 프로젝트로 시작했다.

## 1차 MVP 사용 순서

1. 홈에서 **Record a sound**를 열고 **Start recording**을 누른다. 처음에는 마이크 권한을 요청한다.
2. **Stop and save**를 누르면 원본이 저장되고 다듬기 화면이 열린다. 원하는 구간과 음 높이를 골라 미리 듣고 **Save clip**으로 따로 저장한다.
3. 왼쪽 메뉴의 **Sounds**에서 원본 녹음과 다듬은 소리를 듣거나 다시 다듬는다.
4. 홈의 **Make a song**에서 곡 이름을 입력한 뒤 **Add sound**를 누른다. 사용할 소리, 트랙, 시작 시간을 골라 배치한다. 곡 전체 배치를 위에서 보고, 고른 트랙은 아래에서 확대해 확인한다. 곡을 저장하면 **Songs**에서 재생하거나 편집할 수 있다.
5. **Settings**에 개인 **OpenAI API 키**를 등록한다. **AI Studio**에서 쓸 소리를 고른 뒤 **Make arrangement**를 누른다. 받은 배치는 곡 편집 화면에서 재생하거나 수정해 저장할 수 있다.
6. 앱은 영어로 시작한다. **Settings**에서 영어, 한국어, 일본어, 중국어 간체로 바꾸거나, 녹음 후 다듬기 화면 자동 열기를 끌 수 있다.
