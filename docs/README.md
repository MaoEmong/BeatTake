# Everyday Beats 프로젝트 인수인계

2026년 11월 23일에 정리했다. 프로젝트 위치는 `E:\portfolio\vibeforge`다.

Everyday Beats는 휴대폰으로 주변 소리를 녹음하고, 그 소리들을 여러 트랙에 놓아 음악을 만드는 Flutter 앱이다. 책상 두드리는 소리나 문 닫는 소리처럼 내가 직접 모은 소리로 짧은 곡을 만들 수 있게 하는 것이 목표다. Vibe Forge에 제출할 프로젝트로 시작했다.

## 임시 화면에서 사용하는 순서

1. 안드로이드에서 앱을 열고 마이크 버튼을 누른다. 처음 사용하면 마이크 권한을 요청한다.
2. 녹음 중에는 지난 시간이 표시된다. 정지 버튼을 누르면 휴대폰의 앱 저장공간에 WAV 파일로 저장된다.
3. **저장한 녹음**에서 녹음한 소리를 재생하거나 재생을 멈춘다. 앱을 종료하고 다시 열어도 저장한 파일을 읽어 목록에 보여준다.
4. 원본 녹음 옆의 가위 버튼을 눌러 사용할 구간과 음 높이를 고른다. 미리 듣고 저장하면 **다듬은 소리** 목록에 별도로 나타난다.
5. 상단의 **내 곡**에서 새 곡을 만들고, 다듬은 소리를 원하는 트랙과 시간에 놓는다. 곡을 재생하고 저장하거나 다시 열어서 수정할 수 있다.
6. **AI 설정**에서 개인 Gemini 키를 등록한다. 곡 편집 화면에서 **AI 편곡**을 눌러 소리를 고르면, 배치안을 받아 다시 재생하고 수정할 수 있다.
